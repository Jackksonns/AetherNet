# AetherNet

AetherNet is an image restoration research framework built with design patterns, featuring multiple state-of-the-art models for super-resolution, denoising, and compression artifact removal.

See [README.md](README.md) for full documentation.

## Quick Start

```bash
pip install -r requirements.txt
python scripts/train/train.py --config configs/train_MambaIRv2_SR_x4.yml
```
